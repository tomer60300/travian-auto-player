## Video Reward System — CRACKED (~16:30)

### How ATG ad video rewards work
1. `POST /api/v1/videofeature/open/{type}` → get `vrid` + `videoIframeUrl`
2. `POST /api/v1/videofeature/start` with `{vrid}`
3. Fetch iframe HTML → extract base64-encoded ATG config → get `xsign` (fc/xs URLs + xc state)
4. Send 11 progress ticks to `fc.php` every 3s (~33s total)
5. Call `xs.php` → get XML with `<sign>` hash
6. `POST /api/v1/videofeature/ends` with `{vrid, hash}` → reward granted

### Critical discoveries
- **jQuery.param encoding required** — fc.php ignores JSON bodies entirely. Must use `urlencode(_jquery_param(payload))` to produce `self[ts]=3&self[vrid]=xxx&at=0&rm=30&b=21785&z=3716` format
- **Real 3s timing required** — rapid-fire ticks register in `xc.t` timestamps but xs.php returns empty signature
- **jp parameter = jquery-param module** (not JSON.stringify) — found by tracing ATG JS: `define("vjs",[...,"jquery-param",...],function(...,d,...))` where d=jp
