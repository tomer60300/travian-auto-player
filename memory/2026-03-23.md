## Travian Video Auto-Claim Project

Tomer wanted to automate/skip video ads in **Travian Legends** (ts1.x1.europe.travian.com) to get rewards without watching.

### Wishlist
1. Skip video entirely — instant reward (top wish)
2. Speed up video playback
3. Auto-play (no manual clicks between videos)
4. Parallel video watching

### What we discovered
- Travian video feature API flow:
  1. `POST /api/v1/videofeature/open/<type>` → returns `{vrid, videoIframeUrl}`
  2. `POST /api/v1/videofeature/start` → `{vrid}`
  3. `POST /api/v1/videofeature/ends` → `{vrid, hash}` — hash is the reward claim proof
- Video types: `productionBoost`, `buildingUpgrade`, `adventureDuration`, `adventureDifficulty`, `smithyUpgrade`, `academyResearch`, `lumberProductionBonus`, `clayProductionBonus`, `ironProductionBonus`, `cropProductionBonus`
- The iframe loads from `media.oadts.com` (ATG/OpenX ad network)
- The hash/signature is **server-generated by ATG**, not computed locally

### ATG Signing Flow (the exploit)
- Iframe HTML contains base64-encoded config with `xsign` object
- `xsign.xc` = state object with `{ts, vrid-timestamp-seed}`
- During playback: every 3s, POST to `fc.php` (progress tick) → server updates `xc`
- On video end: POST to `xs.php` with final `xc` state → **returns the signature**
- Signature is passed back to Travian as `hash` in `/videofeature/ends`
- **Exploit**: rapid-fire all progress ticks (~500ms total instead of 30s), get signature, claim reward instantly
