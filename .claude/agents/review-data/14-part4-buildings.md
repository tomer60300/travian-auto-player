# Part IV — Buildings and construction

## IV.1 Queue rules

- **Simultaneous builds:** Gaul and Teuton get **1 slot** (one building *or* one resource field). **Romans get 2** by default — one village-centre building and one resource field concurrently. VERIFIED (support "Quick Summary: Buildings").
- **Travian Plus adds one queued waiting-loop slot.** The extra order starts when a current one finishes; for Romans the third order begins only when one of the first two completes. Resources are required at queue time.
- **Master Builder (Gold Club)** lets you queue builds without having the resources: **1 gold per use, charged when the build starts.** VERIFIED.
- **Cancelling:** cancelling an upgrade to level ≥2 gives a **partial refund**; cancelling a build to level 1 is **fully refunded** (support "Canceling Actions"). **The widely-quoted "90 seconds for a full refund" rule is DISPUTED for current T4** — the 90-second window appears in the October 2024 notes as *cancel troop training within the first 90 seconds*, which is a different mechanic. Verify in-game before encoding either.
- **Instant complete (gold):** free when under 5 minutes remain, otherwise priced by remaining time. **Not available in WW villages.** The mobile video time-reduction is the free analogue.

## IV.2 Prerequisites that actually bind

- **Trade Office:** Marketplace 20 + Stable 10. Directly gates merchant capacity, so it is a logistics decision, not a military one.
- **Tournament Square:** Rally Point 15.
- **Great Barracks / Great Stable:** Barracks 20 / Stable 20, and **not in the capital.**
- **Brewery (Teuton, capital-only):** Granary 20 + Rally Point 10. +1% attack per level to +20%. **Drawbacks while a Mead Festival runs: chief persuasion halved, and catapults hit random targets only.** So it must be off during conquest operations or targeted catapult strikes — a real scheduling interaction if the tool ever automates either.
- **Treasury:** L10 for small artifacts, L20 for large and unique.
- **Palace** (one per account, designates capital) versus **Residence** (cheaper, non-capital).

## IV.3 The gold guard

The tool never spends gold unless explicitly opted in. Worth verifying that this holds for **every** gold-touching path — Master Builder, instant complete, NPC, production bonus — since each is a separate opt-in surface and a missed one spends real money.
